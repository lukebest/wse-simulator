2D Mesh 集合通信逐周期可视化

功能：配置 2D Mesh 形状、集合通信算子和算法实现，查看逐 cycle 的 flit 传输过程、物理 edge 泳道图、逻辑 flow 流水线，并对比 logical butterfly / dim-wise 传输模式与直接在 mesh 上优化的 tree、ring 集合通信算子延迟。 调度模型按 flit 建立依赖：沿路径传播时，某个 flit 到达下一节点后的下一 cycle 即可继续转发，不等待同一 block 的全部 flit。 Logical butterfly (pipelined)：无 X/Y stage 屏障、stride 可重叠；争用物理边的并行流分配不同 color； router 每拍只调度该节点上已有数据且未阻塞的 color，不为无数据的预设 color 空转。

指标说明：延迟为最后一个 flit 离开最后一条 edge 后的 cycle 数；Max edge sharing 表示同一 cycle 同一有向物理 edge 上重叠的 flit 数，理想无冲突时为 1。
