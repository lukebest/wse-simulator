无阻塞、无冲突集合通信：时间展开图综合报告

在 2D Mesh 上将 Broadcast · Reduce · AllReduce · AllGather · Gather · AllToAll 映射为时间展开 DAG 上的边-时隙占用；采用 节点内联归约（inline-reduce） 模型，给出 makespan 下界、无冲突构造，以及 Router 时隙表最短深度 分析。

理论：docs/time-expanded graph.md §9 · AllGather 专题：hamilton_ring_allgather.html · 代码：wsesim/network/collective_patterns.py

1. 模型：inline-reduce 时间展开图

与严格「禁止合流」不同，inline-reduce 允许同一节点、同一时隙多路入边，在 PE 内归约后再转发；每条有向边在每个 slot 仍至多 1 flit（链路无冲突）。

最小化 makespan Z s.t. ∀ 有向边 e, slot t: Σ_f x_{f,e,t} ≤ 1
  • z*：inline-reduce 下界（离心率 / 直径 / 接收度 / bisection）
  • Z：实际调度 makespan（= 一次性 Router 表深度 Z_router）
  • L*：最大有向边负载 → 周期 Router 表最短帧 P_min

2. 六类集合通信：下界与构造

Broadcast

z* = ecc(r)

行+列多播树；Z=6/14/26 @ 4×4/8×8/12×16

P_min=1 · stall=0

Reduce

z* = ecc(r)

反向多播 + inline reduce

P_min=1 · stall=0

AllReduce

z* = D = X+Y−2

双向维累加（X 扫 + Y 扫）

P_min=1 · stall=0

AllGather

z* = ⌈(N−1)/2⌉

Hamilton 双向环流水线

Z = L* · stall=0

Gather

z* = ⌈(N−1)/deg⌉

Hamilton 环向根汇聚

P_min < Z · stall=0

AllToAll

z* = max(⌈NX/4⌉,⌈NY/4⌉)

XY 单播 + 贪心调度

stall > 0 · Z > z*

3.3 关键结论

  • 全局最短周期表：P_min = 1 对 Broadcast / Reduce / AllReduce 成立（单 slot 静态规则循环即可）。
  • AllGather 表长紧：Hamilton 方案 Z_router = L* = ⌈(N−1)/2⌉，一次性与周期同长，且 stall=0。
  • Gather 周期可更短：P_min = ⌈(N−1)/deg⌉ 而 Z = ⌈(N−1)/2⌉（如 8×8：16 vs 32）。
  • AllToAll：边负载给出 L* 下界，贪心 XY 调度 Z > z* 且 stall 大；需更大表或更优算法。

5. AllGather：Hamilton 环（与专题报告一致）

偶数列 mesh 上的 Hamilton 环 + CW/CCW 双向流水线，makespan 达 ⌈(N−1)/2⌉，优于 dim-wise XY 维序。

T* = ⌈(N−1)/2⌉ = Z = L* · stall = 0 · peak = 1
