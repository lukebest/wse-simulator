无阻塞、无冲突集合通信：时间展开图综合报告

在 2D Mesh 上将 Broadcast · Reduce · AllReduce · AllGather · Gather · AllToAll 映射为时间展开 DAG 上的边-时隙占用；采用 节点内联归约（inline-reduce） 模型，给出 makespan 下界、无冲突构造，以及 Router 时隙表最短深度 分析。

理论：docs/time-expanded graph.md §9 · AllGather 专题：hamilton_ring_allgather.html · 代码：wsesim/network/collective_patterns.py

1. 模型：多播 + inline-reduce 时间展开图

每个节点的 router 同时具备两种能力（链路约束不变：每条有向边在每个 slot 至多 1 flit）：

  • 多播 / fan-out：同一入边的 flit 可在同拍复制到多条出边（broadcast / 树分叉 W→E+S）。
  • inline-reduce / fan-in：同一节点、同一时隙多路入边可在 PE 内归约后再转发（reduce / allreduce 累加），即放宽「禁止合流」。
最小化 makespan Z s.t. ∀ 有向边 e, slot t: Σ_f x_{f,e,t} ≤ 1

三个尺度需区分（详见 §3）：

  • z*：下界（离心率 / 直径 / 接收度 / bisection）。
  • Z = Z_router：实际调度 makespan = 一次性 Router 表深度（填满所需 slot 数）。
  • P_min：静态转发规则周期 —— router 开关设置逐拍不变时为 1（环 / 树 / 维扫均如此）。
  • L*：最大有向边 color 重数（每源一个 VN 时的「色表深度」），≠ P_min。

3.3 关键结论

  • 静态转发规则周期 P_min = 1（普适）：Broadcast / Reduce / AllReduce / Hamilton AllGather / Hamilton Gather 的 router 开关设置逐拍不变（树分叉、维扫、环转发都是时不变规则），故最小规则周期均为 1。
  • L* 是色表深度，不是规则周期：若每源用独立 VN color，AllGather 单边承载 L*=⌈(N−1)/2⌉ 个 color；但这等于 makespan，是「填满」时间，而非静态规则周期。
  • 一次性 makespan Z：Broadcast/Reduce Z=ecc；AllReduce Z=D；AllGather Z=⌈(N−1)/2⌉；Gather Z=⌈(N−1)/2⌉（环填满），下界 ⌈(N−1)/deg⌉。
  • AllToAll：贪心 XY 基线 Z > z* 且 stall 大；二相 stall=0 构造已实现并经 verify_preassigned_slots 验证（peak=1, stall=0），Z=44/272/1366 @ 4×4/8×8/12×16（§5.1）。

5. AllGather：Hamilton 环（与专题报告一致）

偶数列 mesh 上的 Hamilton 环 + CW/CCW 双向流水线，makespan 达 ⌈(N−1)/2⌉，优于 dim-wise XY 维序。

T* = ⌈(N−1)/2⌉ = Z = L* · stall = 0 · peak = 1

详见 hamilton_ring_allgather.html（含 4×4 环闭合 15→0 图示）。

5.1 AllToAll 的 z 最短无冲突（stall=0）方案

本报告 §4 的 AllToAll 用贪心 XY 单播 + 在线源端等待：链路 peak=1，但注入不是预排的，故 stall>0。要做到真正 stall=0（注入时刻全部预排、flit 一路刚性 +1/跳、无源端等待），需要一份预计算的无冲突日历。下界与最短构造如下。

下界（bisection）

z* = max( N·cols/4 , N·rows/4 )

竖切把 N 节点分两半，(N/2)²=N²/4 条消息须穿过 rows 条切边，单边至少 N²/4 / rows = N·cols/4 拍；横切同理。任何 stall=0 日历都不可能短于 z*。

最短已知构造：二相维序 + 区间着色

把 XY 路径天然拆成「行段→列段」两相，每相是若干独立的一维全交换，用区间着色给出闭式无冲突注入相位：

  1. 相 X（行内）：在每一行的 cols 节点上做一维全交换——节点 (sx,sy) 把发往「列 dx」的整束（含该列各行目的，rows flit）沿行送到 (dx,sy)。东向消息 (sx<dx) 占用行链 sx..dx−1，相位 φ = sx + g，g 为区间着色层号（重叠区间得不同 g，色数 = 最忙行链负载 = L*_x）。如此每条有向行链每拍 ≤1 flit。西向独立同理。
  2. 相切换（PE 中继）：中间节点 (dx,sy) 把行汇聚的束 eject 进 PE，再沿列 re-inject（一次 PE_INOUT_LATENCY）。这是 inline 模型下的 buffered relay，不是 NoC 源端竞争 stall。
  3. 相 Y（列内）：在每一列做一维全交换，(dx,sy)→(dx,dy)，相位区间着色同上，色数 = L*_y。
Z_a2a = (cols + L*_x) + PE + (rows + L*_y) ≈ N·cols/4 + N·rows/4

实测（build_alltoall_twophase_flows + verify_preassigned_slots）：Z = 44 / 272 / 1366 对 4×4 / 8×8 / 12×16，即 z* 的 2.75× / 2.13× / 1.78×（小 mesh 受固定 PE=10 拉高，大 mesh 趋于 2×）。peak=1, stall=0 全部验证通过。

权衡与现状

  • stall=0 vs makespan：二相构造保证 stall=0、peak=1，代价是 Z≈2·z*（串行两相）；§4 的贪心 XY makespan 更接近 z*，但有在线源端 stall。两者是「零等待 vs 短 makespan」的取舍。
  • 逼近 z*：环面（torus）可用「步进轮转」单相日历精确达 z*；开放 mesh 单相精确 z* 无简单闭式，属调度搜索问题。
  • 实现状态：二相 stall=0 调度器已实现（collective_patterns.build_alltoall_twophase_flows），§4 表含其实测行；贪心基线行并列对照。可视化见 color_mesh_viz.html 的 all-to-all variant=「二相 stall=0」。

6. 多周期链路时延（h > 1，如 h=4）

6.1 模型扩展

前文默认链路 1 cycle。链路时延为 h cycle 时，采用流水线链路模型（latency h、initiation interval = 1）：flit 在 slot t 上链、t+h 到达；同一链路每 cycle 仍可启动 1 条新 flit。冲突约束不变（每 (有向边, 发射slot) ≤ 1 flit），新增单 flit 跨 hop 间距约束 t_{j+1} ≥ t_j + h（验证器 verify_hop_spacing）。

6.2 下界结构定理：距离项 × h，带宽项 × 1

所有下界拆为两类：距离项（单 flit 走 k 跳需 k·h cycle，随 h 缩放）与带宽/串行化项（链路 II=1 不变，不随 h 缩放）。z*_h = max(h·距离项, 带宽项)（实现：optimal_z_lower_bound_h()）：

集合通信z*_h 下界主导项（h=4 典型）达界方案
Broadcast / Reduceh·ecc(r)距离膨胀多播树，紧
AllReduceh·D距离膨胀维累加，紧
AllGathermax(h·D, ⌈(N−1)/2⌉)视 N/D 与 h膨胀 Hamilton = h·⌈(N−1)/2⌉，有 gap（见 6.4）
Gathermax(h·ecc(r), ⌈(N−1)/deg(r)⌉)同上同上
AllToAllmax(⌈N·cols/4⌉, ⌈N·rows/4⌉, h·D)带宽（bisection）stride-h 二相，加性开销

6.3 两条达界路线（均已实现验证）

  • 时间膨胀 dilation（dilate_slots(flows, h)）：把任意 h=1 无冲突日历做 slot t → h·t。映射单射 ⇒ (边, slot) 唯一性保持；相邻 hop t, t+1 → h·t, h·t+h 自动满足间距。代价 Z_h = h·Z_1。距离主导的 collective（Broadcast/Reduce/AllReduce）膨胀即最优：实测 h=4 膨胀广播树 peak=1, stall=0，到达时刻 = 4·ecc = 24 / 56（4×4 / 8×8）恰为下界。
  • 跨步装配 stride-h packing（build_alltoall_twophase_flows(hop_latency=h)）：带宽主导的 AllToAll 不能膨胀——膨胀会把不该缩放的带宽项也 ×h。改法：区间着色 first-fit 改为检查 φ, φ+h, φ+2h, …，单 flit 各 hop 间距 h，但同一链路不同 flit 仍按 1 flit/cycle 密排，带宽项不受 h 影响，h 只贡献加性尾巴 O(h·(cols+rows))。

6.5 AllGather/Gather 的固有 gap 与摊销

  • 膨胀 Hamilton 到达时刻 h·⌈(N−1)/2⌉（h=4 实测：4×4 → 32，8×8 → 128），而下界 max(h·D, ⌈(N−1)/2⌉) = 24 / 56：gap 因子最大 min(h, ⌈(N−1)/2⌉/D)。根因：环转发的「接收 → 转发」串行依赖把链路利用率压到 1/h，这是单 flit 块的固有时延代价（更宽的多路径树形 allgather 属开放调度问题）。
  • 大块摊销：块大小 F ≥ h flits 时，同块身位 flits 以 II=1 跟进填满空 slot，时延被摊销回带宽口径 Z ≈ F·⌈(N−1)/2⌉ + h·D——即增大消息粒度是隐藏多周期链路时延的首选手段。
