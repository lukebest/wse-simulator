无阻塞、无冲突集合通信：时间展开图综合报告

在 2D Mesh 上将 Broadcast · Reduce · AllReduce · AllGather · Gather · AllToAll 映射为时间展开 DAG 上的边-时隙占用；采用 节点内联归约（inline-reduce） 模型，给出 makespan 下界、无冲突构造，以及 Router 时隙表最短深度 分析。

理论：docs/time-expanded graph.md §9 · AllGather 专题：hamilton_ring_allgather.html · 代码：wsesim/network/collective_patterns.py

1. 模型：多播 + inline-reduce 时间展开图

每个节点的 router 同时具备两种能力（链路约束不变：每条有向边在每个 slot 至多 1 flit）：

  • 多播 / fan-out：同一入边的 flit 可在同拍复制到多条出边（broadcast / 树分叉 W→E+S）。
  • inline-reduce / fan-in：同一节点、同一时隙多路入边可在 PE 内归约后再转发（reduce / allreduce 累加），即放宽「禁止合流」。
最小化 makespan Z s.t. ∀ 有向边 e, slot t: Σ_f x_{f,e,t} ≤ 1

三个尺度需区分（详见 §3）：

  • z*：下界（离心率 / 直径 / 接收度 / bisection）。
  • Z = Z_router：实际调度 makespan = 一次性 Router 表深度（填满所需 slot 数）。
  • P_min：静态转发规则周期 —— router 开关设置逐拍不变时为 1（环 / 树 / 维扫均如此）。
  • L*：最大有向边 color 重数（每源一个 VN 时的「色表深度」），≠ P_min。

3.3 关键结论

  • 静态转发规则周期 P_min = 1（普适）：Broadcast / Reduce / AllReduce / Hamilton AllGather / Hamilton Gather 的 router 开关设置逐拍不变（树分叉、维扫、环转发都是时不变规则），故最小规则周期均为 1。
  • L* 是色表深度，不是规则周期：若每源用独立 VN color，AllGather 单边承载 L*=⌈(N−1)/2⌉ 个 color；但这等于 makespan，是「填满」时间，而非静态规则周期。
  • 一次性 makespan Z：Broadcast/Reduce Z=ecc；AllReduce Z=D；AllGather Z=⌈(N−1)/2⌉；Gather Z=⌈(N−1)/2⌉（环填满），下界 ⌈(N−1)/deg⌉。
  • AllToAll：本报告用贪心 XY，Z > z* 且 stall 大；但存在达 bisection 下界的无冲突 stall=0 构造（§5.1）。

5. AllGather：Hamilton 环（与专题报告一致）

偶数列 mesh 上的 Hamilton 环 + CW/CCW 双向流水线，makespan 达 ⌈(N−1)/2⌉，优于 dim-wise XY 维序。

T* = ⌈(N−1)/2⌉ = Z = L* · stall = 0 · peak = 1

详见 hamilton_ring_allgather.html（含 4×4 环闭合 15→0 图示）。

5.1 AllToAll 的无冲突（stall=0）方案

本报告 §4 的 AllToAll 用贪心 XY 单播，故 stall>0 且 Z>z*。但达到 bisection 下界 z*=max(⌈NX/4⌉,⌈NY/4⌉) 的预分配无冲突构造是存在的（本仓库尚未实现）：

  • 置换轮转：把全置换分解为 N−1 个无冲突置换（round-robin / Latin square），每个置换一相位，逐相位预分配 slot ⇒ peak=1, stall=0。
  • 维度分解：先各行内沿 X 做全交换 → 隐式转置 → 各列内沿 Y 做全交换；每相位为无冲突维扫，规则周期 1。

两者均可 stall=0，makespan 受 bisection 限制（不可低于 z*）。报告表中的贪心结果仅作压力基线。
