Color VN 集合通信逐周期可视化

本页展示 Color 虚拟网络（VN） 机制下的 2D Mesh 集合通信调度，与 collective-mesh-viz.html 的逻辑 butterfly / tree / ring 算法视图互补。 每条 flit 携带 catalog color ID，沿编译期静态路由表（方向总线或 XY/YX 单播）逐 hop 前进； 不同 color 可在不同物理链路上并行，同 color 同链路则时分复用。 调度模型：start = delay_cycles，period = 1，路径由 expandPath(plan, src, dst, color) 展开。 节点内部用线性 index（node = row×cols + col），显示为 (x,y) 其中 x=列、y=行。

指标说明：Makespan 为最后一个 flit 离开最后一条 edge 的 cycle；Distinct colors 为本次 collective 使用的 catalog ID 数；Peak edge sharing 为同一 cycle 同一有向物理 edge 上重叠 flit 数（理想无冲突为 1）。
