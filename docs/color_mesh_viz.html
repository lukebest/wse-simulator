Color VN 集合通信逐周期可视化

本页展示 Color 虚拟网络（VN） 机制下的 2D Mesh 集合通信调度，与 collective-mesh-viz.html 的逻辑 butterfly / tree / ring 算法视图互补。 每条端到端流分配独立 color（时分虚拟网，数量不限）；路径为固定 XY 维序路由。 每个 router 具备 多播：calendar 用 源端口→目的端口（E/W/S/N 为 router 四向端口，非行进方向）表示连接（如 W→E 西口入东口出、W→E+S 西口入东/南口出、PE→E 本地注入东口、端口缓冲 W:■）；每 hop 占 1 cycle，每个节点每个 cycle 更新四向端口状态。 集合通信前为各 router 预配置 color calendar；全局调度保证同一 cycle 同一物理 edge 至多一个 flit。 Broadcast 用行/列多播树（共享 color bus）；Gather 为每 PE 向 root 的 XY 流；Reduce 为 2D 树：先列内逐级归约到 root 行，再行内到 root（每跳单周期，中间节点本地 reduce，非全量汇聚到 root）； All-reduce 为维度序 RHD：先横向（X）再纵向（Y）递归减半/加倍交换（与 collective-mesh-viz dim-wise exchange 一致），非树归约+多播。 All-gather 为维度序 RHD（X/Y stride 从大到小），每阶段 flit 数随已收集块数倍增，使每 PE 最终持有全体 rows×cols 份数据块。 调度策略固定为 T=1（无 router 缓冲）：任意 router 在 cycle t 入口的数据必须在 t+1 从出口发出；冲突时仅在源端 PE 等待注入（PE:wait），中间 router 不缓冲。 节点 index：node = row×cols + col，显示 (x,y) 为列、行。

指标说明：Makespan 为最后 flit 占用最后一条 edge 的 cycle+1；Colors 为 VN 流条数；Peak edge sharing 恒为 1（calendar 调度无冲突）；Router buffering 恒为 0（无中间缓冲）；Source stall 为源端等待注入总拍数。
