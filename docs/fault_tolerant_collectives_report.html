WSE 制造坏点容错：集合通信退化分析

在 2D Mesh 上注入 PE 坏点 / 链路坏 / PE 坏块，按角 · 边 · 中心区域分类，对六类集合通信执行绕行重路由 / 哈密顿结构重建，并用统一调度器 schedule_bufferless_noc 量测 makespan 退化。

健康基线：conflict_free_collectives_report.html · 代码：wsesim/network/collective_faults.py

1. 坏点分类

故障类型

  • PE 坏点：节点 (x,y) 不能作源/汇/转发/多播/inline-reduce
  • 链路坏：有向边失效，两端 PE 仍存活
  • PE 坏块：连续 2×2 区域全部失效

区域位置

  • 角（degree 2）：root (0,0) 或对称角点
  • 边（degree 3）：mesh 边界非角
  • 中心（degree 4）：内部 transit 枢纽

结构事实

  • Mesh 是二部图（x+y 奇偶着色）
  • N 偶时去掉 1 个 PE → 色类失衡 → 不存在哈密顿环
  • AllGather/Gather 最坏从环 ⌈(N−1)/2⌉ 退化为路径 N−2（≈2×）

2. 各集合通信容错处理方案

Pattern处理方案预期退化机制
Broadcast多播树剪枝 + BFS 绕行断链ecc 增量（+2 绕洞）
Reduce反向多播树重路由 + inline reduce同 Broadcast
AllReduce维累加流逐边绕行加权直径 D_w 增量
AllGather挖洞网格重建哈密顿路径/环；链路坏局部 detour环→路径 ≈2×；链路坏 +O(1)
Gather哈密顿路径向 root 汇聚同 AllGather + root 度约束
AllToAllXY 单播全量 BFS 绕行bisection 负载 + 绕行尾巴；中心 > 角

测量口径：健康与故障均用 schedule_bufferless_noc 公平复跑；退化比 = Z_faulty / Z_healthy（节点减少时标注「部分流」）。表中 z_healthy_ref 为无冲突预排程参照（见健康报告）。

5. WSE 冗余旁路（工程框定）

Cerebras WSE 采用行/列冗余核：制造坏 PE 在编译/映射阶段被旁路到同行/同列备用核，逻辑阵列对外仍呈现「无缺陷」矩形。本报告的主计算口径是抽象 mesh 挖洞 + 绕行，给出退化下界/上界：

  • 旁路成功时，逻辑 mesh 无坏点，集合通信退化 = 0（与健康报告一致）
  • 旁路失败或坏块超冗余预算时，退化为本报告的挖洞模型
  • 旁路可能拉长物理链路（备用核在阵列边缘），等价于各向异性时延 hx/hy 增大（见健康报告 §6.6）
