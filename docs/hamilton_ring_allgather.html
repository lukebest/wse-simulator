哈密顿环 AllGather：时间展开图上的最优无冲突调度

将 2D Mesh 上的集合通信映射为时间展开 DAG中的边-时隙占用问题；哈密顿环双向流水线在开放 Mesh 上达到 makespan ⌈(N−1)/2⌉，且无 stall、无合流。

实现：wsesim/network/collective_patterns.py · 验证：tests/test_hamilton_allgather.py

1. 问题形式化：时间展开长方体

设 2D Mesh 节点集 V = {(x,y)}，N = XY。构造时间展开图 𝒢T：

  • 顶点：(v, z)，z = 0…T
  • 弧：(v,z) → (w,z+1) 当且仅当 (v,w) ∈ E（每拍恰好一跳，无驻留）
  • 每条弧容量 1 flit；禁止合流（同一中间顶点入度 ≤ 1）；允许分叉（多播）
  • 目标：最小化 makespan T

2. AllGather 下界

接收度下界（角节点主导）： 角节点度数 2，需接收 N−1 个 flit → T ≥ ⌈(N−1)/2⌉
直径下界： T ≥ X + Y − 2
对分下界： T ≥ X/2

对 4×4、8×8、12×16，⌈(N−1)/2⌉ 均为紧约束（角节点接收能力）。

3. 哈密顿环双向流水线（最优构造）

3.1 蛇形哈密顿环（X 为偶数）

3.2 时隙表（全部源 z=0 同时注入）

记环序 π(0…N−1)，T* = ⌈(N−1)/2⌉。
时隙 z（z = 0…T*−1）：
• 顺时针边 π(j) → π(j+1) 承载源 π(j−z) 的 flit
• 逆时针边 π(j) → π(j−1) 承载源 π(j+z) 的 flit

3.3 正确性要点

  • 无冲突： 固定 z，源 s₁ ≠ s₂ 占用不同环边索引 (pos(s)+z) mod N
  • 无合流： 每源流是出树（链式路径），中间节点入度 1
  • 覆盖： z = T*−1 后每节点持有双侧距离 ≤ T* 的 flit，共 2T*+1 ≥ N 份
  • 最优： makespan = T* = ⌈(N−1)/2⌉，等于接收度下界

4. 与 Dim-wise RHD AllGather 对比

Dim-wise 方案（build_dimwise_allgather_flows）分两阶段：先行内 RHD 扩张，再列内 RHD。第二阶段列端点只有 1 条入链却要收 X(Y−1) 个 flit，故

Tdim ≥ (X−1) + X(Y−1) = N − 1

约为哈密顿环方案的 2 倍（开放 Mesh 角节点度数瓶颈未被全程打满）。
